#
# Format:
#   - one branch name per line, resolved against the `origin` remote
#   - order matters: branches are applied top to bottom
#   - `#` starts a comment, either on its own line or after a branch name
#   - surrounding whitespace is ignored
#

# its comment links the upstream PR that carries the same change, so once that PR
# merges the branch can be dropped from this list. See MISTRAL_README.md.
#
# Commits already present upstream (by patch id) or already applied by an
# earlier branch in this list are skipped automatically.
